FLAPPY DUNK — PWA PACKAGE

Files:
- index.html       Game
- manifest.json    Installable-app metadata
- sw.js            Offline/service-worker support
- icons/           App icons

To package it as an Android app:
1. Put this folder on an HTTPS web host.
2. Open the public HTTPS URL in PWABuilder.
3. Choose the Android package option and generate the app package.

The game is already wired as a PWA with a manifest and service worker.
